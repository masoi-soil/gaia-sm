GAIA 2026 SM画面 使い方
v15対応

0. 最初にやること（当日より前に）

  1. サイトを開く（共有の設定はもう入っています。URLや合言葉の入力は要りません）
  2. 名前を入れて「はじめる」（無線で使う呼び名と同じに）
  3. Safariの共有ボタン → 「ホーム画面に追加」（全画面で開けて、誤タップで消えなくなります）

名前を入れないと記録ができません。

🧪 本番前（9/19 14:00より前）は練習モードです。自由に押して試してOK。押しの数字は本番まで出ませんし、本番前に統括が記録を全部消します。まず触って慣れてください。

1. 覚えるのは3つだけ

  1. 音が出た瞬間 → 緑「◯◯が始まった」
  2. 音が止まった瞬間 → 青「◯◯が終わった」
  3. 何か起きたら → 下の「トラブル」
押した記録は全員と統括に自動で届きます。LINEで報告文を打つ必要はありません。

2. 画面の見方

  1. ① 左上＝いまの時刻。右の「押し ◯分」＝予定よりどれだけ遅れているか（緑=15分未満／黄=15分〜／赤=30分〜。赤は統括に連絡）
  1. ② 「● つながっています」＝記録が全員に届く状態。黄や赤になったら電波を確認（記録は端末に貯まるので消えません）
  2. ③ いまカード＝本番中のアクトと残り時間。ボタンはいま押すべき1つだけ出ます
  3. ④ 「最近の動き」＝誰が何を押したか。自分の記録がここに出れば届いています
  4. ⑤ その下＝前後のタイムテーブル。全部見たいときは下の「タイテ」

3. シフト中にやること

  • 交代したらまず、いまカードの「🔒 交代するときはここをタップ」→ OK（記録できるのは1台だけ。前の人は押せなくなります）
  • 音が出たら緑を押す。押すと青に変わります
  • 音が止まったら青を押す。押すと次のアクトの緑に変わります
  • 転換中は「経過」のタイマーを見る（目安15分。赤くなったら急ぐ）
  • 押しが黄色になったら転換で縮める。赤（30分）になりそうなら統括にLINE

4. 困ったとき早見表

  • 押し間違えた
    → ボタンの下「さっきの記録を取り消す」（直近1件だけ戻せます）
  • 押し忘れた
    → 黄色い「押し忘れていませんか？」が出る → 「予定どおりで埋めて次へ」
  • ボタンが薄くて押せない
    → 別の人が記録担当。「🔒 交代するときはここをタップ」で自分に
  • 「● 未送信」「● 送れていません」
    → 電波を確認。記録は端末に残っていて、つながったら自動で送られます。設定 → 困ったとき → 「今すぐ同期」
  • 画面が変・動かない
    → 設定 → 困ったとき → 「画面を再読み込み」（記録は消えません）
  • 名前を入れ忘れた
    → 設定 → あなた → 名前を入れて保存
  • 昼で画面が見えない
    → 右上の ☀ で昼モード

5. トラブルが起きたら

  1. 下の「トラブル」→ 起きたことをタップ（よくある6つが先頭）
  2. 出てきた手順のとおりに動く
  3. 落ち着いたら「記録する（全員に共有）」。機材の名前と押し影響（分）を入れる
「統括に上げるのはこの5つだけ。それ以外はその場で決めてOK」

① 30分を超えそうな押し ② 順番変更・尺カット ③ 同じトラブル2回目 ④ アーティストとの交渉 ⑤ 客の退場・天候で中断

「迷ったら止める。再開だけは統括に聞く。」

6. ブースの呼び出し端末が光ったら

※右の写真は設定前のもの。本番の端末では「LINE通知は未設定」「LINEアプリで送る」は出ません。

  • ボタンは「📣 ステマネを呼ぶ」の1つだけ。光ったら最優先。他をやめてブースへ（演者が演奏中に手を離して押した＝自力で直せない）
  • 同時にSM全員のLINEにも「📣【至急】ステマネ呼び出し」が飛びます
  • 用件は着いてから口頭で聞く（ドリンク・音・機材のどれか）
  • 対応したら端末の「SM対応中 / DONE」を押す（押すまで光り続けます）

7. やってはいけないこと

  • 設定の「🔒 統括のみ」を開かない（全員の画面が変わります）
  • 「記録を全消去」「打刻だけリセット」を押さない
  • 1台のスマホを複数人で使わない（誰が押したか分からなくなります）
  • スマホの時刻設定を日本以外にしない（記録がズレます）
  • 配布リンクを外に出さない

8. 緊急時の電話（救護・警備は無線に乗っていません）

「場所、事象、人数、SMの◯◯です」

例：「メインステージ下手袖、意識のある転倒1名、救護お願いします。SMの◯◯です」

意識がない／呼吸が怪しい／けいれん／頭を打った → 迷わず119

9. （統括だけ）オーガナイザー用の現状ページ

  • 設定 → 「🔒 統括のみ」→「現状ページのリンクを作る（オーガナイザー用）」でリンクをコピーして渡す
  • 渡した人は見るだけ。押し・本番中のアクト・未対応の呼び出し・最近の動き・トラブルが見えます。押すボタンはありません
  • 関係者限定。SNSなどには出さない
わからなければ統括（マソイ / YUKI.T）にLINE。聞いて怒られることはありません。
